# 中国人学日语教程 JapaneseLearn

> 专为中文母语者设计的系统性日语学习教程

## 📚 教程介绍

本教程专为中文母语者设计，充分利用你已有的汉字优势，帮你高效学习日语。

### ✨ 教程特点

- 📖 **系统性**：从零基础到日常对话的完整学习路径
- 🇨🇳 **针对性强**：针对中文母语者的优势与难点设计
- 📝 **实用优先**：重点学习日常交流所需的日语
- 🎯 **循序渐进**：每周学习计划，科学安排进度
- 💡 **易学易懂**：中文解释，对比学习

## 💡 学习建议

### 每日学习时间分配（建议30-60分钟）

```
10分钟：复习昨天内容
15分钟：学习新知识点
10分钟：练习书写
10分钟：听力训练
15分钟：口语练习
```

### 每周学习计划

- **周一至周五**：学习新课内容，做配套练习
- **周六**：复习一周内容，查漏补缺
- **周日**：休息或看日剧/动漫培养语感

### 学习工具推荐

1. **电子词典**：沪江小D、有道词典
2. **五十音图APP**：日语学习助手
3. **听力练习**：NHK新闻、日剧
4. **书写练习**：Anki卡片、Notion

- ✅ 阅读和理解简单的日语文章
